# 英文會考作戰室

國中教育會考英語科分為閱讀與聽力。本站保留官方閱讀題本與自訂練習功能；聽力因官方未公開逐字稿或音檔，不重建成電子試卷。

## 小考規則

- 單元小考固定 20 題、20 分鐘、四選一，無閱讀題組。
- 5 份領域總複習固定 50 題、50 分鐘：44 題一般選擇題，加兩篇閱讀各 3 題。
- 小考只測本單元或本領域的文法、詞性判斷、句型、搭配、構詞與用法。
- 小考不做單字翻譯測驗，也不要求 2000 字全覆蓋；單字考試未來另開功能。
- 同一種子碼從第一份做到最後一份，題面、選項與模板鍵都不得重複。
- 5 份領域總複習只能從該領域的單元抽題，閱讀題組也必須掛在該領域單元內。

## 內容

- 20 個英文單元講義：時態文法、詞類修飾、句型結構、閱讀技巧與核心用法。
- 20 份單元小考與 5 份領域總複習。
- 自訂英文模擬考仍維持 30 題、40 分鐘，作為文法與閱讀技巧混合練習。
- 近十年官方閱讀題本與逐題分析只使用官方已公開資料。

## 維護規則

- 小考不得出現詞意配對、英中互翻、2000 字覆蓋排程或 `Item ...:` 題號前綴。
- `vocab-3000.json` 保留給會考 3000 單字庫頁面，不作為小考出題來源。
- 學生可見內容維持純文字，不加入圖片、圖形、音檔或非選擇題。
