# Publisher lecture reference policy

At execution time identify current approved editions and lawfully accessible publisher lecture materials, public samples, chapter outlines, glossaries, teacher resources, activity descriptions, and errata.

Create a reference record per subject/grade/semester/resource containing:
- publisher and edition/date;
- approval/catalog evidence where applicable;
- access and copyright status;
- curriculum-code links;
- chapter/lesson/topic metadata;
- teaching sequence and prerequisite observations;
- terminology/notation differences;
- examples, representations, source types, experiments, and question-form categories;
- common misconceptions or cautions;
- whether and how the observation improved original production content.

Rules:
1. Official curriculum nodes remain the scope authority.
2. Publisher wording/order alone does not create an atomic skill.
3. A publisher-only point is enrichment unless supported by official authority.
4. Do not copy protected prose, questions, answer explanations, images, maps, or audio.
5. Missing proprietary full-text access is not a blocker; use lawful metadata/public resources and proceed from official scope.
6. Production explanations and questions must be independently written and provenance-checked.
