# Figure, map, audio, and data policy

Create original or properly licensed assets. Every asset requires stable ID, creator/source, license, transformation record, subject/skill links, caption, alt text, long description where necessary, and nonvisual data table.

Maps must include scale/orientation/legend/projection as relevant and must not distort the tested relationship. Historical boundary maps require date and uncertainty notes. Geography data must state year/source.

Science diagrams must be physically/biologically accurate and distinguish schematic from scale drawings. Graph axes, units, significant figures, and controlled variables must be explicit.

English listening audio must match the finalized script exactly, use suitable rate and pauses, provide multiple voices/accents within curriculum-appropriate intelligibility, and have transcript/audio hash linkage. Audio may be locally generated or recorded under a documented license; runtime browser TTS alone is a fallback, not the sole production asset.
