# 使用者交接說明

此包是八科一次性總重建規格，不需再逐科貼提示或逐批核准。

## 權威定位
- 必教範圍：官方十二年國教第四學習階段「學習表現＋學習內容＋附錄」。
- 題型與能力校準：官方106年至115年會考題本、答案、勘誤、說明與英聽資料。
- 出版社講義：僅作教學參考，用來找遺漏、比較順序、名詞、例型、圖表、實驗及易錯點；不得凌駕課綱，也不得未授權複製。

## 一次性執行
Codex必須在同一項工作內依序完成英文、國文、地理、歷史、公民、生物、理化、地科，再完成整合社會與自然。可以建立內部commit與續作狀態，但不得每科回來要求使用者確認。

## 最終審核
內容全部凍結後，進行一次最高規格全量最終審核。所有講義、題目、選項、詳解、文章、聽力、寫作、圖表、地圖、替代文字、操作文字與網站呈現都要逐一讀過或解過；抽查和自動PASS無效。修正後的檔案必須以新雜湊重新審核。

## 發布
八科、整合社會/自然、既有數學回歸、瀏覽器、無障礙、離線、遷移、版權及乾淨checkout閘門全部通過後，才可更新main並發布GitHub Pages。最終報告必須提供可重現證據和實際上線網址。
