# Math V2 人工內容 Batch 007 — U06 完整套件

本套件完整提供 U06「比例式」的人工撰寫與人工審查來源內容。

## 範圍

- 12 個鎖定技能
- 12 篇零基礎完整講義
- 144 題單選題，每技能 12 題
- 24 題非選擇題，每技能 2 題
- 144 筆逐題語意審查
- 3 張必要 SVG 圖形及其精確繪圖規格
- 難度總數：basic、standard、advanced、literacy 各 36 題
- 答案位置總數：0、1、2、3 各 36 題

## 信任與隔離

所有講義、題目、解答、評分規準、語意審查與繪圖規格均標記
`CHATGPT_HUMAN_AUTHORED_R1`。舊 production 題庫、舊講義、舊生成器內容與舊語意審查未被讀取、匯入、改寫或採納。

本套件禁止啟用 production，禁止刪除舊資料庫，且交付 ZIP 中不存在 `staging/`。
`staging/` 只能由中央總負責人核准後，在乾淨解壓副本中執行 emitter 產生。

## 使用順序

1. 先在乾淨解壓目錄執行 `node importer/verify-bundle.mjs`。
2. 中央總負責人確認預期 Git HEAD 與整合順序。
3. 核准後才可依 `CURSOR-INSTRUCTIONS.md` 交由 Cursor 執行。
4. emitter 只序列化已審查來源，不得生成或修補數學內容。
5. 第二次執行 verifier，確認 staging modules 與來源內容一致。

U06 對連比只做共同比項的預備銜接；完整連比內容保留給 U18。
