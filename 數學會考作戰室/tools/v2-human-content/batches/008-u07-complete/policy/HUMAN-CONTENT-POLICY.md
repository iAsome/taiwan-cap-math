# U07 Human Content Policy

## Authority

All teaching records in this package carry `CHATGPT_HUMAN_AUTHORED_R1`. ChatGPT authored and independently reviewed the mathematical content. Cursor is implementation-only and may not generate, paraphrase, repair, shorten, expand, or substitute any lecture, question, answer, explanation, rubric, semantic review, or drawing specification.

## Locked scope

- Unit: U07 一元一次不等式
- Locked skills: 12
- Taiwan junior-high CAP scope only
- Multiplying or dividing both sides by a negative number reverses the inequality sign
- Quadratic inequalities and high-school interval notation are excluded

## Isolation

Old production lectures, questions, semantic evidence, compiled banks, and generators are untrusted and were not used. This package does not modify production runtime and cannot be activated before the final 23-unit release gate.

## Individuality

Each lecture, MC item, constructed-response item, rubric, and review has a skill-specific mathematical purpose. Code in this package only serializes reviewed content, calculates hashes, validates invariants, emits staging modules, and checks duplicates or SVG assertions.

## Integration rule

`CENTRAL_COORDINATOR_APPROVAL_REQUIRED`. Integration must stop if the supplied repository HEAD differs from the coordinator-approved expected HEAD. The old database remains untouched until a separately approved final retirement migration.
