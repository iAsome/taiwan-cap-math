# Math V2 Human Content — Batch 022 U21

本套件完成鎖定單元 `u21`「二次函數」的 12 個技能。內容面向臺灣國中零基礎學生至國中教育會考滿分準備，包含 12 份講義、144 題四選一、24 題非選擇題、144 份逐題語意審查與 12 張技能專用 SVG。

## 信任邊界

舊正式題庫、舊講義、舊語意審查、舊自動產生器與舊編譯題庫均未被讀取或用作題目靈感。套件只沿用鎖定課綱的 ID、順序、先備關係、範圍，以及既有人工批次的結構與驗證慣例。

## 使用限制

本套件不得直接啟用正式環境。`CURSOR-INSTRUCTIONS.md` 必須先由中央總協調對話核准並補入正確 Git HEAD。
