Run `node importer/verify-bundle.mjs` on a clean extraction. After central approval only, `node importer/emit-unit-modules.mjs` may create local staging modules for verification; staging must not be committed as part of this immutable source ZIP unless the coordinator explicitly changes the integration plan.
