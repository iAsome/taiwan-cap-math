# Human Content Policy — Batch 010 U09

## Authority and isolation

Every lecture, multiple-choice item, constructed-response item, semantic review and drawing specification in this package is authored under `CHATGPT_HUMAN_AUTHORED_R1`.

Legacy production questions, lectures, generated reviews, compiled banks and automatic generators are not evidence and were not used. This package does not delete, edit, merge with or activate the legacy database.

## Authoring rules

- Preserve the locked U09 skill IDs, topic IDs, order and prerequisites.
- Write all teaching content in Traditional Chinese used in Taiwan.
- Define every symbol and method before use.
- Keep one uniquely correct answer in every multiple-choice item.
- Require independent recomputation rather than trusting stored answers.
- Use question-specific distractor analysis, review evidence and constructed-response rubrics.
- Reject number-only, name-only and unit-only variants.
- Add figures only when they materially support the mathematics.
- Keep quartiles and box plots outside U09 because they belong to U22.

## Integration boundary

Production activation is forbidden. Cursor may only copy the centrally approved immutable package, run validators and emit staging modules. Cursor must not generate, rewrite or repair mathematical content.

The central coordinator alone controls expected Git HEAD, integration order, cross-unit duplicate reconciliation, legacy retirement and the final release gate.
